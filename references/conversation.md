# 对话模板：带不懂技术的用户走完镜像

配合 [执行手册](runbook.md)。原则：每一步只让用户做一件事，说清楚点哪里、会看到什么、做完回来说什么；AI 自己读日志和对账，不让用户判断成败。

## 0. 说话原则

- 用户只做 👤 的事：双击一个文件、输一次密码、在某个界面点一个按钮、截一张图。（手册里的 👤 和 `mirror_check` 输出里的 👉 人工项是同一类事。）
- **Windows 用户**：本页的 `.command`、系统设置路径都是 macOS 的；Windows 每一步对用户说的话用 `manifest.json` 里 `steps_win` 的 `say`（`py -3 scripts/next_step.py` 会原样打印），其余原则相同。
- 每次让用户动手前先说"做完会看到什么"，做完后 AI 读日志再回话，不问"成功了吗"。
- 失败就说哪一步、什么原因、下一步是什么；不说"应该没问题"。
- 不让用户切换出口节点、退出 Clash、关 TUN；用户正在用 Claude 时不让 Clash 重新激活。

## 1. 开场（G0/G1）

- **介入点 ①（先问，再查）**：出口节点名（要写进 `mirror.params.json`，不然对账是对着参考机的节点算的）、机器上是否已经有 IPv6 守护（AI 自己 `ls /Library/LaunchDaemons | grep -i ipv6` 看，不用问）、是否同意关 IPv6、是否同意装防火墙规则和描述文件；Windows 还要问时区。
- **对用户说**："你的出口节点在 Clash 里叫什么名字？我把它记进本机参数，然后按清单把这台机器现在的状态查一遍，不改任何东西。"
- **AI 动作**：写 `mirror.params.json` → `python3 scripts/mirror_check.py`。
- **对用户说**："查完了：{照 `合计` 行报：✅ {N}、❌ {M}、❓ {U}，共 {T} 项}，需要你动手的有 {K} 步。还差的是：{按步列出，每步一句话}。"

## 2. Clash（S1）

- **对用户说**："先把 Clash Verge 配成参考机的样子。把你的节点参数给我（服务器、端口、UUID/密码、SNI 等），我生成一份配置文件；这些参数只在你电脑上，不会进仓库。"
- **AI 动作**：`render.py --component clash --nodes …`。
- **介入点 ②**："在 Clash Verge 里：配置 → 新建 → 本地 → 选这个文件 `{路径}`；点这张卡设为当前（脚本不用绑，配置里已经带了同样的 DNS 和 STUN 规则）。然后 设置 里打开 TUN 模式，代理 页把『出口选择』点成『{节点名}』，把『Google出口』点成另一个节点（不要和 Claude 的出口相同，不然 Gemini 会说不支持地区）。做完回来说一声。"
- **AI 动作**：对账 S1 的全部组件（`next_step` 打印的那条 `--only` 命令）。对用户说 ✅/❌ 结果；❌ 时说具体在界面上改哪里。

## 3. 装防火墙三道墙（S2–S4）

- **对用户说（S2 前）**："接下来装第一道墙：Claude 的真实地址只允许从代理出去。双击 `installers/安装Claude直连墙.command`，会弹出终端让你输开机密码（输入时不显示字符，输完回车）。看到『安装结束，按回车关闭』就回来。"
- **AI 动作**：读 `installers/logs/direct-wall-*.log` 尾部 `EXIT=`，对账。
- **对用户说（成功）**："装好了：{贴 ✅ 行}。" **（EXIT=72）**："这道墙已经在了，我先对账看它是不是好的……" **（EXIT=73）**："前置没过或 pf.conf 语法没过（日志里写着是哪一样）。pf.conf 已经恢复，但之前复制进系统的文件可能还在，再装会被 72 挡住。我先看日志和对账，先不要重试，要不要清掉由你决定。"
- S3 同样："第二道墙：Anthropic 整段网络也只准走代理。双击 `安装Anthropic整段墙.command`。"
- **对用户说（S4 前，必须先说）**："第三道墙装上以后，你这个账户的所有公网连接都只能走 Clash；以后 Clash 一关，电脑就上不了网（这是故意的，防泄露）。同意的话双击 `安装防泄露墙.command`。" 不同意则跳过并记入交付。

## 4. 更新器、守护、IPv6、体检（S5–S8）

- S5："双击 `安装地址更新器.command`。它会装一条只放行几个命令的免密规则，让更新器每 15 分钟自己刷新 Claude 的地址。装完等 15 秒会显示首轮结果。"
- S6："双击 `安装自检守护.command`。它每分钟检查三道墙和 Clash，有问题会在右上角弹通知。"
- S7："把 IPv6 关掉并守住，防止绕过代理。双击 `安装IPv6守护.command`。"（AI 先 `ls /Library/LaunchDaemons | grep -i ipv6`：已有别的 label 的守护就只改 `mirror.params.json` 的 `ipv6_guard_label`，不让用户装；装了被 EXIT=72 拒绝也是同一个原因。）
- S8："最后装一个体检命令，以后在终端打 `claude-wall status` 就能看防护状态（提示找不到命令就打全路径 `~/.local/bin/claude-wall status`）。双击 `安装体检工具.command`，这个不用密码。"
- 每一步 AI 都读对应日志并对账后再给下一步。

## 5. Chrome（S9）

- **介入点 ③**："Chrome 要装一个描述文件来关掉 WebRTC 直连和浏览器自带 DoH。双击 `installers/Chrome策略.mobileconfig`，系统会说『已下载描述文件』；然后打开 系统设置 → 通用 → 设备管理，选中『Claude 环境镜像：Chrome 防泄露策略』→ 安装 → 密码。装好回来说一声。"
- **AI 动作**：`mirror_check --only chrome.policy`。
- **介入点 ④**："现在把 Chrome 完全退出（⌘Q，不是关窗口）再打开，然后打开 `chrome://policy` 截一张图给我；再打开这个文件 `{assets/webrtc-test.html 路径}` 等 7 秒截一张。"
- **对用户说（读图后）**："策略已生效（平台 / 强制 / 正常），WebRTC 没有公网地址候选。"

## 6. 系统设置（S10）

- "时区：系统设置 → 通用 → 日期与时间，关掉自动设置，选 {Claude 出口所在国家的时区}（不能是中国大陆、香港、澳门；东京、新加坡这些都可以）。"
- 语言（可选）："系统语言顺序现在中文第一，检测页会加 24 分风险。改成英文第一界面会变英文，你决定，不改也可以。"

## 7. 最终验收（S11–S12）

- **AI 动作**：`mirror_check --only net.exit_ip,dns.upstream`，再全量。
- **介入点 ⑤**："用 Chrome 打开 https://ippure.com/claude.html，等它跑完，截两张：页面上半部分（出口 IP、WebRTC、DNS）和滚到底的分数。"
- **交付时说**："清单 {合计行『共 N 项』的 N} 项：✅ {N}，人工项 WebRTC 已截图通过，语言顺序按你的决定保留。ippure：出口 {IP 城市}、WebRTC 未发现泄露、DNS 全部 {国家}、中文环境 {分}。没做的：{未授权跳过 / Firefox / 硬件信息}。日志和截图在 {目录}。"

## 8. 必须停下来的情况

| 情况 | 对用户说 |
|---|---|
| `clash.exit` 分组里有 DIRECT | "你的出口分组里有『DIRECT』，这会让 Claude 偶尔直连。在 Clash Verge 的配置里把它去掉后我再继续。" |
| S4 前 TUN 不在 | "现在 TUN 没开，这时候装第三道墙会立刻断网。先在 Clash Verge 设置里把 TUN 模式打开。" |
| 用户要求切节点测试 | "出口固定是硬规则，我不会切节点；这项我会标『未验证』。" |
| 用户在用 Claude 时要重新激活 Clash | "重新激活会闪断几秒，可能把你正在用的 Claude 会话断掉。等你不用的时候再做这一步。" |
| 日志 `EXIT=` 不是 0 且不是 72 | "在『{步骤}』停下了，原因是 {日志原文}。我先不重试。" |
| 用户想让 AI 自己输密码 / 自己 sudo | "安装只能由你双击并输密码，我负责生成文件、读日志和对账。" |
